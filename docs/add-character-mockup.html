Add a character

Five ways the search box could look, each with the character's real icon, bigger. Shown with batterboi on Kronos (his real avatar; the other numbers match what Nexon reports).

  • The icon in the search result: the server downloads it with the search and sends it along, so the page still never contacts Nexon (that's why it's a stand-in today).
  • Nexon's avatars are 96 × 96 pixel art: shown at exactly 1.5× (144 px) or 2× (192 px) with sharp pixels, so they stay crisp.
  • Same everywhere: + opens it, Search / Enter looks up the name, Add saves the character and selects it; Escape or a click outside closes it.

A · Bigger result card today's box, bigger icon

The box you have now, under the +, with the icon at 1.5× beside the name, and the ranks added. Add stays on the right.

Good for the smallest change; the page underneath stays visible.Less good 144 px is big, but not the biggest.

To decide

  1. Which layout: A, B, C, D or E (or parts of several).
  2. Icon size: 1.5× (144 px) or 2× (192 px)? Bigger than 2× starts to look blocky.
  3. How much to show before adding: just name, level and job, or also the EXP bar, ranks and Legion?
  4. The tabs' icons (38 px today): keep small, or make them bigger too?
